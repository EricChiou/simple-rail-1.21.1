# T-026 使用者後續確認（2026-09-28）

使用者原文：

> 1. 確認高速鐵軌已有斜坡模式，且通過測試。
> 2. 坡底反轉狀況仍存在，偶爾發生(約10%機率)，且另外確認不一定是動力鐵軌銜接高速鐵軌才會發生，任何鐵軌接高速鐵軌(包跨高速鐵軌自己本身)皆有可能發生。

I-026-01 高速斜坡子項依使用者確認記為人工通過，不要求附件。I-026-02 仍人工不通過，範圍擴及一般／動力／高速軌銜接高速軌，包含高速接自身；約 10% 為使用者估計，沒有補造次數、速度、受測 JAR 雜湊或逐方向結果。整項 T-026 未結案；其他未明示案例不推定通過。

先前「坡底往上坡、有供電、各速度都有可能」保留。是否純平坦直線也發生仍待確認；未指定的幾何、礦車占用／其他實體碰撞及設定 0.4 的獨立發生次數待確認，不作為必須提交的人工證據。

R1「缺少有效坡型」推論不能解釋已成坡後仍反轉的全部回報，保留為歷史，不能繼續當成完整根因或已修復。[R2 來源／數值分析與局部修正](fix-R2/README.md)只針對已證實的幾何碰撞路徑，人工修復效果待重測；R-03／R-F 仍待審。
