## 固定編號與展開規則

C-001–C-044固定，不隨子案例數量變動。表中的集合必須逐項展開並留下每項結果：例如`C-005/<recipe-ID>`，`C-001/<registry>/<ID>`，`C-031/<SP或DS>/<單車或編組>/<方塊朝向>/<來車方向>/<供電>`。不能以一張「正常」截圖代表整個矩陣通過。

方向一律以世界座標及getMotionDirection候選語意記錄，不混用「來自東側」與「向東行駛」。左右Y各4×4×2=32組方向，在單車／編組及SP／DS分別展開；十字依四方向及供電分列。多狀態相互影響、零速、過車中切電另記邊界子例。13配方、11掉落、13物品和9軌共用速度不得抽掉成員。
