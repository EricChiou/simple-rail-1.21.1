# T-052 R1 速度重測失敗與 R2 使用者決策

日期：2026-10-01（本流程紀錄日期）。使用者原文：

> 火車頭還是比一般礦車慢太多，火車頭改成繼承一般礦車，速度機制跟一般礦車保持一致，只是互動模式改成不能坐上去

此回報確認 **R1 速度問題仍存在**，要求 R2 改用一般礦車父類。使用者沒有回報 R1 熔爐外觀是否通過、其餘 T-052 子案例結果、受測 JAR 指紋或測量數值；不代填。T-052 繼續列人工驗收失敗／未結案。新行為決策：車頭速度／阻力／軌道處理由一般礦車父類提供；正常互動不能乘坐。這取代 R1 保留熔爐燃料機制的開發選擇，不改 D1–D8 或既有 ID。
