# T-058-R4 使用者操作案例

全部案例使用 [R4 固定 JAR](README.md)；實際結果待使用者確認。直線間距請待車頭走過至少整列長度且路線已累積後觀察；剛連結、剛讀回或瞬移後可能暫用 R3 停靠格，不能把此過渡當作穩態數值。

| 案例 | 操作步驟 | 預期結果 | 可選回報 |
| --- | --- | --- | --- |
| T058-R4-01 中車斷鏈 | 車頭連 A、B、C 前進後停下，摧毀中間 B，再開動。 | A 繼續跟車；B 消失；C 自編組斷開，不再被車頭定位；扳手重新接回只能新增一次。 | A／C 是否仍跟車；可附 `Train` NBT。 |
| T058-R4-02 暫時卸載 | 連結三節，離開使編組區塊卸載，再返回；可存檔重啟。 | UUID、次序與連結保留；全部載入後可重新跟車。 | 是否仍連結；可附 NBT／log。 |
| T058-R4-03 直線間距 | 平坦長直線連結車頭＋A、B、C，前進至少整列長度後，在穩定行進與停車時觀察。 | 沿車頭已走路線，第 1、2、3 節目標距車頭約 1.25、2.5、3.75 格，相鄰目標約 1.25 格；無重疊或無故斷鏈。初始路線不足時先用舊停靠格定位。 | 描述行進／停車時車距；可附側面影片。 |
| T058-R4-04 彎道與坡道 | 同一編組經過轉彎、上坡和下坡，再停下。 | 車廂順序不亂；目標沿已經過的方塊中心路線量距，不直接穿越彎角；高度隨坡段插值。實際軌道貼合與視覺距離由此案例確認。 | 分述轉彎與坡道；可附影片。 |
| T058-R4-05 NEW 世界存讀／瞬移 | 在正常跟車後存檔、退出、重進，再前進；另測車頭長距離瞬移後繼續行駛。 | 原編組 UUID／順序及 `TrainRoute` 可讀回，無重複車廂；瞬移不沿舊路線把車廂拖越世界，重新累積路線後恢復 1.25 倍數間距。 | 讀回／瞬移前後現象；可附 NBT／log。 |
| T058-FULL 原任務回歸 | 面向東／西／南／北，在點擊格兩側連結；檢查格中心 `0.5` 邊界、空格、無車頭、已連結車廂、兩位玩家先後操作；重驗扳手調向／調等級及有車時不改軌道狀態。 | 只在合法情況新增一次，UUID 次序正確；無效點擊不改編組，成功才有煙粒子與鏈條音效；多人狀態一致，既有扳手功能維持。 | 指出失敗場景；可附兩端 log。 |

任一必要案例失敗，T-058 維持未結案；開發修正、獨立 Review Agent 複查程式後，再由使用者重測受影響案例。人工是否通過只依使用者確認。
