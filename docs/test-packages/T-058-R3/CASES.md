# T-058-R3 使用者操作案例

全部案例請使用 [固定 R3 JAR](README.md)；`actual` 待使用者確認。建議先在平坦直線普通軌道用扳手連結車頭＋A、B、C 三節一般礦車，再觀察行進／停車。可在開啟指令的測試世界檢視車頭 `Train` NBT UUID 次序；無須提交紀錄才能結案。

| 案例 | 操作步驟 | 預期結果 | 可選回報 |
| --- | --- | --- | --- |
| T058-R3-01 中間車斷鏈 | 車頭拉動 A、B、C 後停車；摧毀中間 B，再開動。 | A 仍跟車；B 消失；C 從車頭編組斷開而不再被車頭定位。C 若自行沿軌滑動，不等於仍連結。重新用扳手接回只能新增一次。 | A／C 是否仍跟車；可附摧毀前後 `Train` NBT。 |
| T058-R3-02 暫時卸載 | 已連結三節後離開，讓編組所在區塊卸載再返回；可另存檔重啟。 | 車廂 UUID 與順序保留，暫時查不到實體不切斷；全部重新載入後仍跟車。 | 是否仍連結；可附重進前後 NBT／log。 |
| T058-R3-03 直線停靠格 | 在足夠長的平坦直線軌道前進至少兩個編組長度，再停車；觀察各節與格線。 | 車頭每跨一格，第一節採車頭上一格、後節採前一節舊停靠格，已載入車廂移到格中心。穩定直線段相鄰**停靠格中心**通常差一格；車頭與第一節的即時視覺距離隨車頭在格內的位置變化。此版沒有固定 1.5／3.0／4.5 格目標，也不應重疊或無故切鏈。 | 行進與停車時的間距、格中心是否吻合；可附側面影片。 |
| T058-R3-04 彎道與坡道 | 同一列車過彎、上坡、下坡，再停車。 | 每節依先前停靠格的順序跟車，無跳節、無持續重疊或掉軌；彎坡的視覺距離可不同於直線。OLD 來源行為仍待遊戲確認。 | 分別描述轉彎與坡道；可附影片。 |
| T058-R3-05 NEW 世界存讀 | 正常跟車時保存退出，重新進入同一 NEW 世界再前進、停車。 | `Train` 順序、`TrainStops` 與 `PrevPos` 可讀回，停靠格跟車恢復；無重複車廂或意外重新連結。舊 NEW 測試世界若含 R2 `TrainPath`，該欄位被忽略。 | 讀回前後差異；可附 NBT／log。 |
| T058-FULL 原任務回歸 | 分別面向東／西／南／北，在點擊格兩側連結；檢查接近格中心 `0.5` 邊界、空格、無車頭、已連結車廂、兩位玩家先後操作；重驗扳手調向／調等級、點擊格有車時不改軌道狀態。 | 僅合法操作新增一次，UUID 次序正確；無效點擊不改編組，成功才有煙粒子與鏈條音效；多人狀態一致，既有扳手調整未回歸。 | 指出失敗方向與場景；可附兩端 log。 |

任一必要案例失敗，T-058 保持未結案；開發修正、獨立 Review Agent 複查程式後，由使用者重測受影響案例。人工是否通過只依使用者回報。
