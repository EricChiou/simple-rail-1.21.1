# T-058-R1 使用者操作案例

全部案例請使用 [固定 JAR](README.md)；`actual` 待使用者確認。初始編組建議車頭＋至少三節一般礦車，以扳手逐節連結。可用開啟指令的測試世界檢視車頭實體的 `Train` NBT UUID 次序；視覺觀察仍是主要驗收。

| 案例 | 操作步驟 | 預期結果 | 回報方式 |
| --- | --- | --- | --- |
| T058-R1-01 中間車斷鏈 | 在平坦普通軌道連好車頭、A、B、C，讓車頭拉動後停止；摧毀中間 B，再讓車頭前進。 | A 仍屬原車頭並跟車；B 已消失；C 自原編組斷開，不再被車頭 `moveTo` 拉走。車頭 `Train` 只保留 A，C 仍是世界中單獨礦車；再用扳手接回時只新增一次。若普通軌道上的 C 自己滑動，不可單憑移動誤判為仍連結。 | 說明 A／C 各自是否跟車；選用摧毀前後 `Train` NBT、影片或 log。 |
| T058-R1-02 卸載不是摧毀 | 已連結三節車廂後，離開使編組所在區塊卸載，再回到該處；可另存檔重啟。 | 車廂 UUID 與原順序保留，沒有因暫時查不到實體而切斷；全部載入後仍跟車。 | 說明是否仍連結；選用重進前後 `Train` NBT／log。 |
| T058-R1-03 直線小間距 | 將車頭與三節車廂置於足夠長的平坦直線軌道，連結後讓車頭前進至少約兩個完整編組長度，再停下。 | 車廂沿路徑依序跟隨；相鄰車中心沿軌道約 1.2 格，車體之間可見小空隙，停止後不重疊或緊貼。剛連結而車頭尚未走出足夠路徑時，整列可短暫維持原位置。 | 說明行進及停止時的間距；選用側面截圖／影片。 |
| T058-R1-04 彎道與坡道 | 同一列車經過轉彎與上／下坡，再停下。 | 車廂沿車頭走過的路徑通過轉彎／坡道，順序不亂、不抄近路、不重疊或掉軌；距離可因曲率有視覺差異。 | 說明轉彎與坡道各自現象；選用影片。 |
| T058-R1-05 存讀 | 在正常跟車且有間距時保存退出，重新進入同一 NEW 世界，再前進及停下。 | 原編組 UUID／順序、後段斷鏈結果與路徑間距保持；讀回不重複車廂、不意外重新連結。 | 說明讀回前後差異；選用世界備份／log。 |
| T058-FULL 原任務回歸 | 分別面向東／西／南／北，在點擊格兩側連結；檢查接近格中心 `0.5` 邊界、空格、無車頭、已連結車廂、兩位玩家先後操作，並重驗扳手調向／調等級、點擊格有車時不改軌道狀態。 | 僅合法操作新增一次連結且 UUID 次序正確；無效點擊不改編組，成功連結才有煙粒子與鏈條音效；多人看到一致結果；舊扳手屬性調整未回歸。 | 指出失敗的方向／情況；選用 client＋server log 或截圖。 |

若上述任何必要案例未通過，T-058 保持未結案；開發修正後由獨立 Review Agent 複查程式，再由使用者重測受影響案例。人工測試是否通過只依使用者回報。
