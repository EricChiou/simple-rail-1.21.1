# T-052-R1 操作案例（均未執行）

共通條件：client／server 同裝本包固定 JAR，世界中放一條足夠長的原版平直供電軌道與一條等長平行軌道；車頭與普通礦車分別放置，不加煤／木炭，從相同起始方式放行。比較時保持兩車相同的乘客條件及供電狀態。使用者可按實際觀察回報，不必量測精確容差；若希望量測，可記錄等長路段通過時間或使用 `/data get entity` 讀取 Motion，但這不是人工結案必需證據。

| 案例 | 操作步驟 | 預期結果與回報重點 |
| --- | --- | --- |
| T052-R1-01 外觀 | 在平面、轉彎、斜坡放置車頭，靜止與行進時從八方向觀看；雙 client 各觀察一次。 | 只有 Simple Rail 六盒車頭模型；**沒有額外原版熔爐方塊**。保留自訂模型內設計的爐體、朝向、坡度和受損姿態。回報若仍有重疊方塊／缺貼圖。 |
| T052-R1-02 原版動力軌速度 | 在兩條相同的原版平直供電軌道上，分別放無燃料車頭與普通礦車，以相同方式起步；各跑至少 32 格，觀察穩定速度和到達先後，重複兩次。 | 車頭不再被熔爐礦車 `0.2` 軌道 cap 鎖住，能達普通礦車在該軌的速度；若仍明顯慢，回報軌道長度、是否載客、供電與實際現象。 |
| T052-R1-03 滑行／燃料 | 在平軌推動無燃料車頭及普通礦車，觀察放手後滑行；另以煤或木炭供應車頭，確認原燃料推進仍能作用。 | 無燃料時的滑行阻力與同載客狀態普通礦車一致；燃料分支仍能推進，且不額外顯示原版熔爐。回報兩種情況。 |
| T052-R1-04 自訂高速軌與坡道 | 將車頭與普通礦車依次通過相同的高速軌、與原版軌銜接及坡道，含雙方向。 | 車頭可依軌道上限加速，不被熔爐礦車 `0.2` cap 限制；不出現方向反轉或額外熔爐。回報任何回歸。 |
| T052-FULL 原 T-052 全項 | 依 T-052 原要求，以雙 client 連 dedicated server，重驗合法／非法放置、名稱、一次生成、破壞／拾取／掉落、碰撞、8 朝向、轉彎／坡道、新加入／重連、九軌透明與車頭 UV。 | 兩端狀態一致，無重複掉落或缺貼圖，且上述 R1 問題已解。未完成的子項請標「待確認」，不以四個 R1 案例代替整項 T-052。 |

若失敗，回傳案例 ID、預期與實際差異及是否 client／server 同時發生；`logs/latest.log`／截圖選用。R-05／R-F 程式審查與使用者遊戲驗收分開記錄，Agent 不代填 `results.json`。
