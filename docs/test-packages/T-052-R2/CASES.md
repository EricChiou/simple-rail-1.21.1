# T-052-R2 使用者操作案例（均未執行）

共通準備：client／server 同裝 R2 固定 JAR，使用新測試世界。比較速度時，車頭與原版一般礦車皆**不載客、不加燃料**，置於同長度的平行軌道；使用相同推動方式及供電配置。若單次結果不明顯，重複至少兩次並交換軌道。精確測量值、影片或 log 非人工結案必需；失敗時可選擇提供等長路段通過時間或 `/data get entity` 的 `Motion`。

| 案例 | 操作步驟 | 預期與需要回傳的實際觀察 |
| --- | --- | --- |
| T052-R2-01 一般軌道速度 | 車頭與普通礦車分別通過等長平直普通軌道，再通過至少 32 格相同供電的原版動力軌道；同起速、同條件比較到達先後。 | 車頭的起步、加速、最高速度與無人乘坐的普通礦車一致，不再有額外低速 cap／燃料阻力；回報任何持續差距與條件。 |
| T052-R2-02 高速軌與坡道 | 在同配置的 Simple Rail 高速軌、原版軌銜接、平面轉彎與可通行坡道，分別讓車頭及普通礦車通過。 | 車頭沿用普通礦車的軌道移動機制，受相同軌道上限約束；無異常減速、反轉或卡軌。回報出現差異的位置和方向。 |
| T052-R2-03 不可乘坐 | 空手右鍵車頭，蹲下右鍵車頭，再以原版空礦車作對照；單人與 dedicated server 各做一次。 | 玩家不能坐上車頭，空礦車仍可正常乘坐；右鍵車頭不消耗手持物。回報任何可乘坐情況。 |
| T052-R2-04 外觀 | 在八方向、靜止與行進、轉彎與坡道觀察車頭，雙 client 各確認。 | 只有 Simple Rail 自訂六盒模型，不額外顯示原版熔爐方塊；朝向／坡度／受損姿態與貼圖正常。R1 此項沒有使用者通過回報，須重新確認。 |
| T052-R2-05 身分與資料 | 放置有自訂名稱的車頭、破壞／拾取，測重啟後名稱與既有新世界編組資料；可另測煤／木炭對車頭的互動。 | 仍掉落／拾取 `simplerail:locomotive_cart`，不重複掉落；車頭不能以熔爐燃料機制加速，NEW 編組／朝向仍依正式契約保存。既有 R1 測試世界讀回另標待確認。 |
| T052-FULL 原任務全項 | 依 TASK.md 的 T-052，以雙 client 連 dedicated server，重驗合法／非法放置、名稱、數量、破壞／拾取／掉落、碰撞、8 朝向、轉彎／坡道、重連／新加入、九軌透明與車頭 UV。 | 全部 T-052 完成條件由使用者確認；如仍有未測子項，整項保持未結案。 |

若失敗，回傳案例 ID、實際現象、軌道種類／供電／乘客條件；`logs/latest.log` 與截圖為選用。R-05／R-F 程式複查與遊戲實測分開，Agent 不代填結果。
